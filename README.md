# Vanity

A browser makeup editor for Roblox avatars: paint Face, Eyes and Lips makeup on the texture or straight onto a 3D head, then export a Studio-ready `.gltf`.

Unofficial fan tool. Uses the UV layout and reference head from Roblox's public makeup template ([Roblox/avatar](https://github.com/Roblox/avatar/tree/main/Makeup)).
